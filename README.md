# 📈 Stock Market Comparison Dashboard

## 📌 Overview
This project is a real-time Stock Market Comparison Dashboard built using Python and Streamlit. The application fetches stock market data using Yahoo Finance and allows users to compare multiple stocks through interactive charts and financial analysis.

---

## 🚀 Features
- Real-time stock market analysis  
- Multi-stock comparison  
- Interactive price charts  
- Moving average analysis  
- Daily returns analysis  
- Volatility calculation  
- CSV export functionality  
- Financial data visualization dashboard  

---

## 🛠️ Technologies Used
- Python  
- Streamlit  
- Pandas  
- Plotly  
- yFinance  
- Matplotlib
